# Clima

Modern iOS weather application built with SwiftUI featuring dynamic weather data, current location weather support and light/dark mode compatibility.

This project was created as part of my Swift and iOS development learning journey, with additional UI customization and feature implementation.

---

## Features

- Dynamic weather display

- Current location weather support

- City-based weather search

- Light and dark mode support

- Responsive SwiftUI interface

- Clean and modern mobile UI

---

## Technologies Used

- Swift

- SwiftUI

- Core Location

- Weather API

- Xcode
